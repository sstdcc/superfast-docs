# Static Images

Place the following files in this directory:

- `logo.png` — SuperFast logo (recommended: 200×40px, transparent background, white text for dark mode)
- `favicon.ico` — Browser favicon (32×32px)

These files are referenced in `docusaurus.config.ts`:
- `logo.png` → navbar logo (`src: 'img/logo.png'`)
- `favicon.ico` → browser tab icon (`favicon: 'img/favicon.ico'`)

Until you add real assets, Docusaurus will fall back to its default logo.
